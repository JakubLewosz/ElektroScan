# Changes

Create one folder per proposed change:

```text
openspec/changes/<change-id>/
├── proposal.md
├── design.md
├── tasks.md
└── specs/
    └── <capability>/
        └── spec.md
```

Completed changes can be moved to `archive/YYYY-MM-DD-<change-id>/` after their final requirements are reflected in `openspec/specs/`.
